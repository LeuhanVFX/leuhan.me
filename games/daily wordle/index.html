Comment jouer ?

Vous avez jusqu'à 6 tentatives pour trouver un mot caché qui change chaque jour.

À chaque tentative, les lettres changeront de couleur :

  • A Si la lettre est bien placée
  • A Si la lettre est dans le mot mais pas à la bonne place
  • A Si la lettre n'est pas dans le mot
